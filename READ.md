# Shadow Room

An anonymous emotional safe-space social platform developed using the MERN Stack, allowing users to express thoughts, interact anonymously, and access AI-powered support resources.

## Live Demo

🔗 https://shadow-room-iota.vercel.app/

---

## Features

- User Authentication using JWT
- Anonymous Post Creation
- Comment System
- Report Content Feature
- Admin Moderation Dashboard
- AI Chatbot Personas powered by Gemini API
- Responsive User Interface
- Secure Backend APIs

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/shadow-room.git
```

### Install Frontend Dependencies

```bash
cd client
npm install
```

### Install Backend Dependencies

```bash
cd ../server
npm install
```

### Start Backend

```bash
npm start
```

### Start Frontend

```bash
npm run dev
```

---

## Environment Variables

Create a `.env` file inside the server directory and configure:

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_api_key
```

Do not upload actual API keys to GitHub.
